# PDF test set

Put PDFs under `fake/` (AI generated, expected verdict: ai_generated) and `real/` (genuine, expected: not ai_generated).
Subfolders are fine (for example `real/invoices/`, `fake/invoices/`); results are reported per subfolder.

What ships here:

- `fake/gpt_image2_*.pdf`: 10 receipts generated by GPT-Image-2, taken from the public TextRich dataset (`Receipts/1_fake`), from the **test split** the model never trained on.
  Wrapped as PDFs (re-encoded to JPEG, so the AI-generated metadata tag is gone and only the model can catch them); three also have an A4 layout variant (`*_a4.pdf`).
- `real/public_sroie_*.pdf`: 4 genuine scanned receipts from SROIE, also from the test split. They are controls so the folder is not empty; add your own real PDFs next to them.

Not covered: the public data has no AI-generated invoices, so there are no fake invoices here. Add your own to `fake/invoices/` to test them.
The model was trained on receipts only; invoices are untested.

Run: `python scripts/check_pdfs.py` (see the script header for setup).
